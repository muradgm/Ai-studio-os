# outcome-evidence

## Procedure
1. Record the launch hypothesis and measurement intent.
2. Require the launch hypothesis plus metric source type/provenance, baseline, observed value, sample size, and observation window.
3. Require explicit evidence for metric-specific sample/window and meaningful-change thresholds rather than universal guesses.
4. Mark weak measurements as insufficient instead of interpreting them.
5. Default attribution to correlational.
6. Use causal language only when a credible controlled experiment is evidenced.
