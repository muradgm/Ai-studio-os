# Image contract

For real businesses prefer:

Real asset → controlled retouch → generative edit → supporting generation.

If a truthful product image is missing and the final output represents a real product, prefer **new capture** over fabricating a materially different product.

Required routing actions:
- `use`
- `retouch`
- `generative-edit`
- `generate-supporting`
- `capture-required`

Preserve product truth. Do not fabricate a materially different product and present it as real.
