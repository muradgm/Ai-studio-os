# Creative Calibration

## Design read

**Business:** AI-native creative agency application.

**Emotional target:** capable, authored, controlled, surprising when useful—not theatrical by default.

**Category expectation:** dark AI dashboards, gradients, prompt boxes, glowing orbs, model pickers, generic portfolio grids.

**Opportunity:** make the product feel like entering a highly competent contemporary studio: editorial clarity, visible process, strong work surfaces, decisive critique, and crafted output.

**Memorable idea:** **The Workroom** — every project moves through visible rooms/states rather than disappearing into a chat transcript.

**Primary risk:** becoming either a generic SaaS dashboard or an over-styled agency portfolio that obscures utility.

## Creative dials

| Dial | Score / 10 | Rationale |
|---|---:|---|
| Novelty | 7 | Distinct enough to avoid generic AI SaaS, but interaction must remain learnable. |
| Editoriality | 8 | Strong hierarchy and art direction make the work feel authored. |
| Visual density | 5 | Enough information for professional work without dashboard clutter. |
| Asymmetry | 6 | Controlled tension; avoid rigid card grids. |
| Motion intensity | 4 | State-change motion, not decorative animation. |
| Texture | 5 | Use selectively in project/media contexts, not across core UI. |
| Warmth | 4 | Human judgment should appear through language/work, not beige lifestyle styling. |
| Playfulness | 3 | Serious creative tool with occasional wit, not toy-like. |
| Technical spectacle | 3 | Infrastructure should feel capable, not performative. |
| Restraint | 8 | Fewer stronger decisions. |

## Visual language

- monochrome-first system with one controlled accent family per project/workspace
- typography-led hierarchy
- large working canvases rather than stacked marketing cards
- process/status represented through spatial state and clear labels
- media shown at meaningful scale
- dense technical metadata collapses behind review/inspection layers
- deliberate dividers, apertures, gates, and handoff motifs can extend the Bounded Flow logic

## Avoid

- glowing AI orb as brand hero
- glassmorphism as system identity
- endless pill-shaped chips
- bento-grid homepage clichés
- gradient text
- generic floating 3D primitives
- fake film grain everywhere
- excessive serif-as-luxury shorthand
- monospace used as the entire brand personality
