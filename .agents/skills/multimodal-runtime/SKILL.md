# multimodal-runtime

## Procedure
1. Load the approved creative direction, intent, duration, formats, and truth constraints.
2. Build timed beats and shots before media production.
3. Create and enforce a continuity bible across every shot.
4. Direct video, voice, and audio from the same direction packet.
5. Require source/rights evidence for truth-sensitive visuals, voice usage, and commercial music.
6. Run multimodal-review and block production on direction drift, continuity drift, timing errors, rights gaps, or accessibility gaps.
