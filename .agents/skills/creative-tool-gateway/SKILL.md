# creative-tool-gateway

## Procedure
1. Read the asset specification before looking at providers.
2. Enforce truth/source constraints before routing.
3. Match operation, capabilities, availability, budget, and explicit priority.
4. Return capture/source-required or unassigned when no safe adapter exists.
5. Treat every provider as replaceable infrastructure.
