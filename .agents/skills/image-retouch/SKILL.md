# image-retouch

## Procedure
1. Audit source, ownership/licensing status when known, resolution, truth sensitivity, and intended placement.
2. Prefer use or controlled retouch when the source asset is sufficient.
3. Use generative edit only to extend/recompose/clean while preserving the real subject.
4. If a required real product image is unusable or absent, request new capture rather than silently fabricating it.
5. Define crop, tonal treatment, cleanup limits, continuity, and output requirements.
6. Review the result for physical plausibility and product truth.
