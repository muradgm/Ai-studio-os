# analytics-review

## Procedure
1. Read only evidence-qualified metrics.
2. Compare baseline and observed values against each metric's declared direction and meaningful-change threshold.
3. Separate improved, flat, regressed, target-met, and insufficient-evidence outcomes.
4. Treat guardrail regressions as blocking even when primary metrics improve.
5. Preserve absolute and relative movement where useful.
6. Do not infer causation from before/after movement alone.
