# hero-section-design

## Purpose
Design the opening viewport so users quickly understand what this is, why it matters, what makes it credible, and what they can do next—while establishing a distinctive visual world.

## When to use
- New landing pages, launch pages, major homepage redesigns.
- When the hero looks polished but could belong to any company in the category.
- When media/3D/motion is competing with comprehension.

## Inputs required
- Positioning and primary audience.
- Approved headline/message hierarchy.
- Strongest proof/product behavior available above the fold.
- Creative direction and media options.
- Primary/secondary CTA intent.
- Performance, accessibility, responsive, and reduced-motion constraints.

## Operating principles
- The hero is a decision surface, not a poster.
- Do not default to headline left + random 3D object right.
- Visual spectacle must reveal product meaning, proof, or brand behavior.
- One dominant message, one dominant visual idea, one clear primary action.
- Show real product/proof when it is more persuasive than abstract brand imagery.
- Mobile hero must be intentionally recomposed.
- Motion must settle quickly enough for reading and interaction.

## Workflow
1. Define the 5-second comprehension target.
2. Choose the dominant proof mode: product, outcome, evidence, process, or brand narrative.
3. Explore 3 composition structures, not just styling variations.
4. Pair headline, supporting copy, CTA, and visual so each contributes new information.
5. Define hierarchy, focal path, viewport crop, and responsive behavior.
6. If motion/3D is used, specify first frame, settled frame, interaction, and reduced-motion fallback.
7. Test with actual copy length and realistic product/media assets.
8. Remove decorative elements that do not improve comprehension or character.

## Deliverables
- 5-second comprehension statement.
- Hero composition and hierarchy.
- Proof/media rationale.
- CTA hierarchy.
- Desktop/mobile layout behavior.
- First/settled motion states if applicable.
- Performance/accessibility notes.

## Review criteria
- User can identify product/category/value quickly.
- Primary action is obvious.
- Visual concept is specific to the brand/product.
- Copy and visual do not redundantly communicate the same thing.
- Hero works before animation loads.
- Mobile remains intentional rather than compressed.

## Failure modes
- Decorative orb/gradient/3D object with no product meaning.
- Headline obscured by motion or low contrast.
- Two primary CTAs competing equally.
- Fake dashboard or invented metrics used as proof.
- Hero consumes several screens before the page begins.
- Brand distinctiveness depends entirely on a trendy animation.

## Handoffs
- `landing-page-layout` integrates the hero into the complete page narrative.
- `copywriter` and `headline-writing` own verbal refinement.
- `motion-designer` owns hero choreography where motion is justified.
- `creative-critic` and `brand-fit-review` independently challenge the result.
