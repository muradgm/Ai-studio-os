# Benchmark 001 — Du Bonheur

A deterministic creative-runtime fixture for a real-business landing-page redesign.

The benchmark verifies process quality, not visual taste by itself. It checks that inspiration is multi-lane, product truth is preserved, real assets are routed correctly, motion includes reduced-motion behavior, and the creative runtime exposes explicit eval criteria.

Run:

```bash
node ./bin/studio.mjs benchmark du-bonheur
```
