# TraderFrame Icon Calibration — Vector Geometry Review

Verdict: **APPROVE FOR USER VISUAL REVIEW / DO NOT FREEZE YET**

## Family-level findings

- No blocker in the 24×24 construction grammar.
- All icons use the same 1.5 stroke, square caps, miter joins, and dominant angular vocabulary.
- Each icon contains at most one `event` layer.
- Monochrome masters remain semantically legible without Terminal Red.
- The set now has stronger family ownership than the first visual exploration because the frame/gate idea recurs structurally rather than through repeated literal rectangles.

## Per-icon review

### Frame — PASS
Clear at 16px. Balanced footprint. Event corner is meaningful and not decorative.

### Trend — PASS
Intentionally lighter than the enclosed icons. Adding a baseline or second stroke was rejected because it pushed the glyph toward generic chart iconography. Frame-corner terminal is the correct differentiator.

### Watchlist — PASS AFTER REVISION
The earlier two-sided container was too heavy and too close to a generic list panel. The refined version uses one framing rail plus three market rows, reducing visual mass and avoiding bookmark/star cliché.

### Signal — PASS AFTER REVISION
The bullseye concept was rejected. Four alignment axes plus a diamond/event point are lighter, more consistent with TraderFrame geometry, and less stock-icon-like.

### Filter — PASS AFTER REVISION
Top width narrowed to normalize footprint. The event band sits inside the field rather than decorating the outline.

### Risk — PASS AFTER REVISION
Shield footprint reduced. Central event line reads as a boundary/limit and survives monochrome.

## Small-size inspection

Target sizes reviewed: **16 / 20 / 24 / 32px**.

- 16px: all six remain identifiable; event accents are still visible but not required for recognition.
- 20px: stable.
- 24px: canonical size.
- 32px: no geometry reveals unnecessary detail or irregular joins.

## Remaining gate

The only unresolved gate is **visual family approval by the user**. If approved, freeze the DNA and use these six as the calibration anchors for the first 24–32 production icons.
