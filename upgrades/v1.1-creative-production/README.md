# AI Studio OS v1.1 — Creative Production Upgrade

v1.1 is deliberately **not Epoch 006**.

It strengthens the bridge between creative judgment and production execution while keeping the five-epoch v1 core frozen.

## Added flow

`Inspiration → Reference Extraction → Design Read → Creative Dials → Explore → Council → Concept Selection → Creative Direction → Production Mode → Production Recipe → Asset Specs → Tool Gateway → Asset Registry → Design/Image/Motion → Review → Asset Patch`

## Principles

1. References are decomposed and transformed, never cloned.
2. Creative Dials reduce cross-discipline drift; they do not replace judgment.
3. Exploration must produce genuinely different concepts.
4. Providers are adapters. The OS owns the asset requirement and selection rules.
5. Prototype output cannot masquerade as production truth.
6. Truth-sensitive assets prefer real source → controlled edit → new capture before synthetic documentary generation.
7. Stable asset IDs make targeted regeneration, continuity, cost/provenance tracking, and downstream review possible.
8. Asset-level patching is bounded; repeated failure escalates to a creative/production decision rather than infinite regeneration.

## Validation fixture

Benchmark 005 uses Du Bonheur as a deterministic planning fixture. It does not execute external providers or claim that any provider is currently connected or optimal.

## Implementation shape

The upgrade is intentionally consolidated into four subsystems: `creative-calibration`, `production-planning`, `tool-gateway`, and `asset-registry` (including bounded asset patching).
