# logo-review

## Procedure
1. Compare the candidate against the approved brand intent and psychology hypotheses.
2. Separate concept weakness from execution defects.
3. Inspect vector geometry, curve tension, negative space, optical balance, and wordmark spacing.
4. Test small-size/micro-mark behavior and one-color reproduction.
5. Compare against competitive and inspiration references for confusion/copy risk.
6. Return approve, revise, or reject with blocker/major/minor/taste findings.
