# image-direction

## Procedure
1. Inventory required image roles and available source assets.
2. Route each asset through: use → retouch → generative edit → supporting generation / new capture.
3. Mark truth-sensitive assets, especially real products, people, locations, and claims.
4. Define camera/crop, lighting logic, grade, texture, continuity, and output context.
5. Do not replace a missing real signature product with synthetic documentary imagery.
6. Hand every final image set to image-review before approval.
