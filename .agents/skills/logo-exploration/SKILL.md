# logo-exploration

## Purpose
Create disciplined divergence before logo refinement. Produce concept families that differ in idea and construction, not merely styling, color, or typeface.

## When to use
- After brand strategy, logo psychology, and seven-type assessment.
- Before selecting a final logo direction.
- When prior generations repeat the same monogram/frame/arrow idea with cosmetic changes.

## Inputs required
- Brand positioning and desired perceptions.
- Seven-type assessment and shortlisted types.
- Inspiration references with TAKE / REJECT / TRANSFORM.
- Category cliché list and originality risks.
- Required applications and reproduction constraints.

## Operating principles
- Explore 3–5 families; each family must use a different conceptual mechanism.
- Variants within a family can refine one mechanism, but families must not be synonym designs.
- Define the memory hook before judging polish.
- Include kill criteria so weak directions can be rejected early.
- Work in black/white first unless color is structurally essential to the concept.
- Do not mix several weak families into a “best of all worlds” hybrid.

## Workflow
1. Translate strategy into 3–5 possible symbolic/typographic mechanisms.
2. Assign each family a logo type, concept, memory hook, construction rule, and strategic reason.
3. Produce 2–4 variants per family that test proportion, abstraction, and reduction—not random decoration.
4. Test silhouette, 1-second read, small-size potential, category confusion, and AI-generic risk.
5. Write the strongest argument and strongest risk for each family.
6. Reject families that fail their kill criteria before refinement.
7. Hand the surviving shortlist to independent logo review/Council.

## Deliverables
- Concept-family matrix.
- Family rationale and mechanism.
- Variant descriptions/sketches.
- Memory hook per family.
- Kill criteria and risk notes.
- Shortlist recommendation without self-approval.

## Review criteria
- Families are genuinely different.
- Each idea can be explained in one sentence without elaborate mythology.
- The mark has plausible small-size and one-color potential.
- References were transformed rather than copied.
- Weak directions were killed instead of endlessly polished.

## Failure modes
- Nine unrelated icons with no family logic.
- Three versions of the same TF monogram.
- Color/gradient used as the only differentiator.
- Symbolism explanation stronger than the actual visual read.
- Exploring only fashionable logo types.
- Refining the first acceptable output before real divergence.

## Handoffs
- `logo-designer` owns professional refinement and construction decisions.
- `logo-review` independently scores surviving families.
- `creative-skeptic` joins high-risk selections to challenge category imitation.
