# motion-review

## Procedure
1. Identify the purpose of every major motion behavior.
2. Check choreography: attention order, causality, state changes, and idle behavior.
3. Check timing/easing consistency and interaction responsiveness.
4. Check mobile simplification, reduced-motion fallback, and interruption behavior.
5. Flag scroll-jacking, decorative loops, and effects that compete with content.
6. Return blockers, majors, taste notes, and a prioritized correction list.
