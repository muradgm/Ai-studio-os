# logo-inspiration

## Procedure
1. Search LogoLounge for curated/trend/category patterns and attributed examples.
2. Search LogoSystem by type, industry, style, shape, mood, color, and animation where relevant.
3. Use LogoMoose for long-tail identity and packaging context.
4. Use Inspiration Logo for wildcard, negative-space, and brand-book exploration.
5. Extract take/reject/transform notes and provenance for every serious reference.
6. Never use a reference as permission to recreate its exact mark, geometry, lockup, or motion.
