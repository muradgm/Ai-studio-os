# Epoch 001 — Kernel

## Goal
Create the smallest usable control plane for AI Studio OS.

## Exit criteria
- routing definitions are machine-readable
- reasoning/review protocols are explicit
- council presets exist
- Codex Agent Skills are discoverable
- CLI can inspect routes, workflows, and council presets
- validation catches malformed skills or missing kernel files
- benchmark fixture can be routed through the kernel

## Non-goals
- full autonomous multi-agent runtime
- production UI
- provider-specific model orchestration
- deep image/video/audio implementation
- deployment automation
