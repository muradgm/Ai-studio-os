# creative-eval

## Procedure
1. Load the intended outcome and approved creative direction.
2. Score only dimensions supported by evidence.
3. Use the repository creative rubric; AI-generic risk is lower-is-better.
4. Critical failures block approval even if the average score is high.
5. Attach one concrete reason to every non-passing dimension.
6. Return pass/fail, score summary, blockers, and next corrections.
