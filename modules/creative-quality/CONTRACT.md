# Creative Quality contract

Creative Quality evaluates whether an expressive web project has enough authored evidence to be treated as an award-caliber candidate. It is a critique and readiness gate, not an award prediction engine.

**Pass:** one reviewed Creative Thesis, 3-5 structurally different Creative Worlds, explicit human selection, high-fidelity rendered proof, motion/interaction thesis, browser implementation evidence, independent rendered-artifact critique, production delivery evidence, and 2-4 bounded polish loops.

**Block:** missing project truth, missing human selection, cosmetic-only world divergence, missing rendered/browser evidence, missing reduced-motion plan, blocker creative-quality findings, blocker release evidence, or any claim that the work is award-winning/award-ready without external jury evidence.

**Review:** major findings, insufficient rubric evidence, weak memorability/distinctiveness, incomplete polish proof, or production evidence that is measured but not release-ready.

The verdict must remain conservative:

```text
candidate = internally credible award-caliber candidate
review    = promising but not yet internally credible
blocked   = missing core evidence or unsafe claim
```

Never convert a numeric score into an award claim.
