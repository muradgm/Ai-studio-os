# creative-calibration

## Procedure
1. Decompose evidenced references into transferable principles and transformations; reject exact copying.
2. Write the Design Read: business, emotional target, category expectation, opportunity, memorable idea, risks.
3. Set all Creative Dials from 0–10 with concrete rationale.
4. Generate 3–5 genuinely different concepts, not cosmetic variants.
5. Select one concept with evidence, rejected-alternative reasons, and kill criteria.
