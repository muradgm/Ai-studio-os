# design-runtime

## Procedure
1. Load the approved creative direction and business priorities.
2. Define hierarchy before components.
3. Define typography roles, composition rules, density, and image behavior.
4. Define mobile priorities independently from desktop geometry.
5. Define interaction priorities and accessibility constraints.
6. List category/template anti-patterns explicitly.
7. Produce a design work packet that can be implemented or critiqued.
