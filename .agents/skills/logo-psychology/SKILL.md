# logo-psychology

## Procedure
1. Define desired perceptions and audience/application contexts.
2. Evaluate processing fluency, shape semantics, complexity, harmony, abstraction, typography, color context, figure-ground, and distinctiveness/familiarity.
3. Write each choice as a hypothesis with evidence basis, test method, and falsifier.
4. Treat color associations as contextual/cultural rather than universal.
5. Balance ease of processing with distinctiveness instead of optimizing one blindly.
6. Preserve uncertainty and reject pseudo-scientific one-to-one symbolism.
