# Routing policy

Use the smallest sufficient workflow.

## Escalation dimensions
- consequence
- uncertainty
- reversibility
- cost
- novelty

## Council thresholds
- Low: no council.
- Moderate: quick council with skeptic + domain expert + chair.
- High: full council with independent reviews, cross-critique, red team, rebuttal, chair.

## Example routes

### Landing page
Intent → Research → Inspiration → Product → Creative Direction → Image → Design → Motion → Critique → Evals → Learn

### Image retouch
Intent → Asset Audit → Image Direction → Retouch → Image Review → Learn

### SaaS feature
Intent → Question → Research → Product → Council → Design → Engineering → Code Review → Security → QA → Release → Learn
