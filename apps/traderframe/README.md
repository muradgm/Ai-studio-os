# TraderFrame Prototype — The Frame

This is the runnable prototype produced by **TraderFrame Real Project Run 001** using the AI Studio OS specialist-skill architecture.

## Purpose

Validate one creative-direction decision: make the **frame** an information instrument rather than decorative branding.

The prototype intentionally does **not** claim verified product capabilities, market coverage, execution, pricing, performance, latency, or adoption. The product UI is labeled **CONCEPT UI / NOT LIVE DATA**.

## Run

```bash
npm install
npm run dev:traderframe
```

## Build

```bash
npm run build:traderframe
```

## Review gates

- The frame visibly changes information state.
- Vermilion is used sparingly for meaningful change/focus.
- Marketing motion settles into a flat, legible product surface.
- Mobile preserves the idea without recreating desktop spectacle.
- Reduced-motion users receive equivalent hierarchy.
- No unsupported product or performance claims appear in the prototype.
