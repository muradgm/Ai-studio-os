# production-planning

## Procedure
1. Choose prototype or production intentionally.
2. Prototype output must remain visibly non-final.
3. Production requires strict truth, rights, accessibility, and performance expectations.
4. Select a recipe by experience pattern, not provider.
5. Carry mode and recipe gates into tool routing, QA, and release.
