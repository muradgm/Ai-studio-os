# logo-runtime

## Procedure
1. Assess all seven logo types: wordmark, lettermark, pictorial, abstract, mascot, combination, emblem.
2. Shortlist types by brand fit, not fashion.
3. Explore at least three genuinely different concept families with multiple variants.
4. Use raster generation only for ideation; reconstruct finalists as vectors.
5. Freeze an approved canonical mark specification before export.
6. Validate every SVG against shape, palette, layer, overlap, and render-diff locks.
7. Build primary/secondary lockups, symbol, micro mark, wordmark, and favicon.
8. Stress-test monochrome, tiny sizes, digital, print, signage, and low-detail reproduction.
9. Block approval on weak originality, excessive AI-generic risk, reproduction failure, or any unexplained geometry/SVG drift.
