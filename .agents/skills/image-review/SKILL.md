# image-review

## Procedure
1. Compare the output with the source asset and intended use.
2. Check product/character continuity and whether factual appearance changed.
3. Check anatomy, perspective, reflections, shadows, materials, text/signage, and microdetail.
4. Check crop, hierarchy, grade, lighting logic, and consistency across the set.
5. Separate blockers (truth/artifacts) from taste comments.
6. Return approve / revise / reject with evidence.
