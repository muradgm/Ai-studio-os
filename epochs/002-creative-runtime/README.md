# Epoch 002 — Creative Runtime

## Objective

Turn the creative contracts from Epoch 001 into executable, testable runtime primitives.

## Capabilities

1. **Inspiration Engine** — creates a structured research/reference packet with direct-industry, best-in-class, adjacent-industry, trend, anti-reference, and opportunity-gap lanes.
2. **Creative Direction Runtime** — synthesizes product truth and inspiration into authored principles, non-negotiables, and review criteria.
3. **Design Runtime** — creates a design-system work packet covering hierarchy, typography, composition, responsive behavior, interaction, and anti-patterns.
4. **Image Runtime** — routes each asset to use, retouch, generative edit, supporting generation, or new capture.
5. **Motion Runtime** — defines motion personality, timing, choreography, reduced-motion behavior, and performance constraints.
6. **Creative Evals** — evaluates strategic/creative quality using explicit gates, including AI-generic-risk.

## Acceptance criteria

- All runtime outputs are machine-readable JavaScript objects.
- Du Bonheur Benchmark 001 produces all required creative stages.
- Signature product assets are never silently fabricated when real imagery is required.
- Reduced-motion is present in every motion packet.
- Inspiration packets contain both anti-references and opportunity gaps.
- Creative evals can fail an artifact even when its average score is high if a critical dimension fails.

## Non-goal

Epoch 002 does not yet implement production website code, automated browser QA, or external image/audio generation APIs. Those belong to later runtimes.
