# Identity + Product Direction

## Identity direction

**Public name:** The Creative Agency

**Underlying engine:** AI Studio OS v1.2

### Logo architecture

The previous AI Studio OS Bounded Flow direction remains strategically compatible, but the new name changes the wordmark problem. Re-run outcome:

- Combination mark: **9.6/10** — strongest launch form.
- Abstract mark: **9.2/10** — symbol should carry proprietary recognition.
- Wordmark: **7.3/10** — exact phrase is long and descriptively generic; cannot carry distinctiveness alone.
- Lettermark / TCA: **5.8/10** — heavily occupied acronym territory; internal shorthand only.
- Emblem: 4.2/10.
- Pictorial: 3.4/10.
- Mascot: 2.0/10.

### Recommended symbol family

**Bounded Flow v2 — Agency Handoff**

A controlled open structure representing the movement of work between strategy, creation, review, production, and delivery. The open gate represents human approval and intervention.

Rules:
- black/white first
- no sparkle/star/brain/orbit/network symbolism
- no literal “TCA” hidden-letter puzzle unless it arises naturally and survives small-size testing
- no gradient required for recognition
- symbol must work independently from the long name

### Wordmark

Use a restrained grotesk/neo-grotesk with custom spacing and one structural intervention derived from the gate/handoff geometry. The phrase should read as a confident proper name, not as a category label.

## Product architecture — The Workroom

### 1. Lobby
New project, recent work, pending decisions, active reviews.

### 2. Brief Room
Intent, problem, audience, constraints, source assets, truth requirements, business objective.

### 3. Research Desk
Evidence, competitor/context scan, source quality, factual constraints.

### 4. Inspiration Wall
References decomposed into TAKE / REJECT / TRANSFORM. No visual cloning.

### 5. Exploration Floor
3–5 distinct concepts shown side-by-side with creative dials and kill criteria.

### 6. Council Room
Independent specialist opinions, cross-critique, dissent, confidence, verdict.

### 7. Studio
Actual design/image/motion/video/writing/engineering production surface.

### 8. Review Table
Critique, red-team, QA, evals, artifact integrity, revisions.

### 9. Delivery Room
Approved assets, versions, rights/source evidence, export formats, handoff notes.

### 10. Archive / Memory
Decisions, corrections, recurring failures, promoted rules, benchmark outcomes.

## Primary navigation

`Projects / Workroom / Council / Assets / Deliveries / Memory`

Do not expose the 20+ internal OS modules as top-level navigation.

## Hero/product message

**The Creative Agency**

`Bring the problem. Leave with the work.`

Support line:
`Strategy, design, image, motion, video, writing and implementation—run through one accountable creative process.`

Alternative message for product UI rather than marketing:
`Start with the brief, not the model.`

## Signature interaction

Every project has a visible project spine:

`BRIEF → RESEARCH → EXPLORE → DECIDE → MAKE → REVIEW → DELIVER`

The spine is not a stepper decoration. Each state exposes unresolved decisions, evidence, outputs and approval gates.
