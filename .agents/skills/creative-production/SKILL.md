# creative-production

## Procedure
1. Require a ready Creative Calibration packet and selected concept.
2. Bind Design, Image, Motion, recipes, tool routing, and assets to one Creative Direction.
3. Choose Prototype or Production mode explicitly.
4. Route asset specs through the Creative Tool Gateway and register every asset/version.
5. Patch only validated weak assets and require integration review.
