# landing-page-layout

## Purpose
Design the page's spatial and narrative structure before visual polish. Decide how information, proof, product, media, and calls to action unfold across the page.

## When to use
- New marketing/launch pages.
- Major redesigns where the current page feels template-driven.
- When sections exist but the narrative rhythm and hierarchy are weak.

## Inputs required
- Audience, objective, offer, and desired action.
- Message hierarchy and verified proof.
- Creative direction and content/media inventory.
- Product interaction or demo requirements.
- Responsive, accessibility, and performance constraints.

## Operating principles
- Layout should tell the product story, not merely organize modules.
- Do not default to Hero → logo strip → 3 cards → testimonials → pricing → CTA.
- Let the strongest proof or product behavior influence page structure.
- Use repetition and rhythm deliberately; not every section needs a new visual pattern.
- Control density and whitespace based on content importance, not a “premium” aesthetic formula.
- Mobile is recomposition, not desktop shrinkage.
- Keep the CTA hierarchy stable even when composition becomes expressive.

## Workflow
1. Define the page's single primary conversion/decision.
2. Order the message/proof sequence by user questions and objections.
3. Identify which sections should show product, evidence, narrative, or atmosphere.
4. Explore 2–4 composition models with materially different rhythms.
5. Select one model and define grid, max widths, asymmetry, density, section transitions, and responsive shifts.
6. Place real copy/media approximations to test content pressure.
7. Remove sections that repeat an idea or exist only because competitors use them.
8. Validate scan path, CTA visibility, accessibility, and implementation realism.

## Deliverables
- Narrative/section spine.
- Composition model and grid logic.
- Density/whitespace rules.
- Responsive reflow notes.
- Media/product placement plan.
- CTA hierarchy.
- Sections explicitly removed/rejected.

## Review criteria
- Page can be understood from headings and major visuals alone.
- Structure feels specific to the offer rather than a template.
- Proof appears close to the claims it supports.
- Rhythm has intentional contrast without becoming chaotic.
- Mobile preserves narrative and action hierarchy.

## Failure modes
- Card grid as the default solution to every content type.
- Hero doing all the storytelling while the rest of the page becomes filler.
- Excessively long page because every stakeholder idea became a section.
- Decorative asymmetry that harms reading order.
- Desktop-only art direction that collapses on mobile.
- Fake metrics/logos inserted to make the layout feel credible.

## Handoffs
- `hero-section-design` handles the opening composition in detail.
- `copywriter` adapts message length and hierarchy to the layout.
- `art-direction` governs visual language.
- `landing-page-recipe` composes research, layout, copy, image/motion, review, and implementation.
